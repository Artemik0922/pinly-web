# Векторы: умная лента и поиск по фото

Обе функции включаются одним ключом `EMBED_API_KEY` и индексом. Без них сайт
остаётся обычным: деградация прозрачна для пользователя и не ломает ни один
тест.

## Умная лента

Для вошедших первые ~80% страницы подбираются по вектору вкуса: сумма векторов
лайкнутых (вес 1) и сохранённых (вес 2) пинов из `.cache/vectors.json`, и
ближайшие к ней пины, кроме уже отмеченных. Остальные ~20% — обычная ротация
категорий. Подборка кэшируется на 10 минут, id лайков и сохранений отдаёт
`GET /api/taste/pins`.

## Поиск по фото

`POST /api/search/image` принимает картинку до 5 МБ — тип определяется по
сигнатуре байтов, а не по заголовку запроса, — отдаёт её в
`voyageai/voyage-multimodal-3.5` и ищет ближайшие векторы в том же
`.cache/vectors.json`. Модель мультимодальная: текст и картинка лежат в одном
пространстве, поэтому запрос-фото находит и пины, проиндексированные по тексту.

Отдельный проход `npm run index -- --images` добавляет в индекс векторы самих
картинок: так «найди похожее» сравнивает фотографию с фотографией, а стиль и
композиция в тексте описаны плохо.

### Порядок включения

```bash
EMBED_API_KEY=…               # web/.env.local, скрипты читают файл сами
npm start                     # сайт + прокси картинок
npm run warm                  # кэш ленты и оригиналов
npm run index                 # текстовые векторы
npm run index -- --images     # векторы картинок
npm run probe:embeddings      # что принимает провайдер и совместим ли индекс
```

### Честные состояния вместо пустой сетки

| Ситуация | Ответ |
| --- | --- |
| нет ключа или индекса | 503 с объяснением, что запустить |
| мусор вместо картинки | 400 |
| больше 5 МБ | 413 |
| провайдер молчит | 502 и кнопка «Попробовать ещё» |

Каждый запрос — платный вызов API, поэтому частота ограничена 20 в минуту на
адрес. Счётчик живёт в памяти процесса, смысл его — «не спамь», а не квота.

## Про формат запроса к роутеру

Формат запроса с картинкой RouterAI в документации не описан:
[`src/lib/server/providers/embeddings-wire.mjs`](../src/lib/server/providers/embeddings-wire.mjs)
перебирает три правдоподобных и запоминает победителя.

Замер без ключа 2026-10-31: `/embeddings` жив (401 со штатным JSON),
`/multimodalembeddings` — `404 page not found`, значит собственные
voyage-эндпоинты роутер не проксирует.

Какой формат принят на самом деле, видно по `npm run probe:embeddings` — он же
проверяет, что косинус «текст своего пина ↔ картинка своего пина» выше, чем до
чужого пина. Без этой проверки индекс можно построить неправильно и заметить
это только по качеству поиска.

## Размерность

У `voyage-multimodal-3.5` размерность берётся из 2048/1024/512/256 — 768 она не
умеет. Значения задаются `EMBED_DIMENSIONS` и `EMBED_MODEL`; индекс, построенный
в одной размерности, с другой не читается, поэтому менять их после первой
индексации нужно вместе с перестройкой `.cache/vectors.json`.
